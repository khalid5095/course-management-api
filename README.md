# Course Management REST API

A Spring Boot REST API for managing Topics, Courses, and Lessons.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs

## Features

- Manage Topics
- Manage Courses
- Manage Lessons
- CRUD Operations
- JPA Relationships

## API Examples

GET /topics

GET /topics/{topicId}/courses

GET /topics/{topicId}/courses/{courseId}/lessons
